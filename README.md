# Click Repeater — мод для LeviLauncher (Minecraft Bedrock 1.26.52.*, Android arm64-v8a)

**Статус: прототип, на устройстве не проверялся.**

Зажми **Ctrl** и удерживай кнопку мыши: мод повторяет этот клик с заданной скоростью.
Настоящие клики и клавиши мод не блокирует.

## Настройки (меню модов → Click Repeater)
- `LMB repeat` / `RMB repeat` — включить повтор для ЛКМ / ПКМ
- `LMB/RMB clicks per second` — скорость (1–30)
- `LMB/RMB button code` — код кнопки мыши, который присылает лаунчер (по умолчанию 1 = ЛКМ, 2 = ПКМ).
  Менять только если кнопка не реагирует; настоящие коды видны в логе.

## Сборка (GitHub Actions, как у Armor HUD)
1. Создай репозиторий и загрузи в него содержимое этой папки (вместе с `.github`).
2. Вкладка **Actions** → последний запуск → артефакт **ClickRepeater** → скачать.
3. Распакуй, получится `ClickRepeater.levipack` → LeviLauncher → Mods → импорт → включить для 1.26.52.x.

SDK: только заголовки `preloader-android` 0.2.2 (подтягиваются при сборке). Сам preloader в мод не линкуется.

## Что отправить мне после теста
Строки лога с тегом **Click Repeater**:
- `mouse event: button=… down=…` — какие коды приходят при нажатии ЛКМ и ПКМ;
- `injector: …` — нашлась ли Activity, `dispatch action=… handled=… exception=…`;
- `menu module registered: …` и `worker: started`.
И описание: появилось ли меню, шли ли клики в игре.

## Известные неизвестные
1. Принимает ли Minecraft синтетические события мыши (шаг `dispatch`).
2. Доступен ли скрытый API `ActivityThread.mActivities` на твоей версии Android.
3. Клик отправляется в точку (0, 0): в меню игры возможны случайные нажатия, пока зажаты Ctrl и кнопка.
4. Автокликеры могут быть запрещены на серверах — используй в одиночной игре.
